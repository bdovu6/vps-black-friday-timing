## 下单前必须确认的四件事

**1. 退款窗口有多长**

WePC 的规则是 3 天内且流量使用不超过 10GB 可退，全额退到账户余额，或扣每笔 10 元手续费原路退回；超过 3 天或 10GB，只能按比例退到余额，余额不可提现。对比一下：RackNerd 官方条款写明所有 VPS 不支持常规退款；NoslaCloud 是 24 小时内、IP 未墙且用量少于 5GB 才可原路退。3 天/10GB 在这个行业里算中等偏宽松，但"退到余额"和"原路退回"是两回事，下单时看清选哪个。

**2. 流量是单向还是双向**

英国原生家宽那款写的是"1.5TB 双向流量"，双向计费意味着上传下载都算。NoslaCloud 的处理方式是双向计算、耗尽后限速到 1KB，基本等于断网。WePC 美国各款标注超量限速 3M，英国 TikTok 款限速 5M，是限速不停机，这点比直接断流好，但 3M 之后基本只能维持 SSH。

**3. 超流量之后是限速还是停机**

这条决定你要不要买大流量档。做直播或跑同步任务，1.5TB 双向可能一个月就见底，限速后的 3M 撑不住推流码率。预算里要把"提前升级"算进去。

**4. 协议限制**

WePC 英国和美国页面都明确写了"严禁使用 shadowsocks 协议"，搭建教程指向自家 wiki。这是硬性条款，不是建议。买之前确认你的用途和这条不冲突，否则退款窗口内发现也用不了。

## 常见问题

**WePC 黑五有折扣吗？**

英国和美国节点页面目前是常规月付价，没有活动标签和截止日期。会不会在黑五放活动，官网没公告，我不替它承诺。要蹲就盯官网，别信第三方汇总页上的"黑五价"。

**月付还是年付？**

官网这两条产品线挂的是月付。年付要单独问客服，且年付前先用月付跑一周——家宽线路的实际表现和你家宽带运营商强相关，页面上的"三网优化"是商家标注，不是你家的实测结果。

**香港节点能跑 Claude Code 吗？**

不能。香港不在 Anthropic 支持地区列表内。英国、美国节点在列表范围内，但不代表每个 IP 都实测可用。

**限速 3M 是什么概念？**

大约 375KB/s。SSH 和轻量 API 调用没问题，网页能开，视频和推流不行。买之前按你的月流量估一下什么时候会撞线。

**流量用完了会自动扣费吗？**

页面写的是超量限速，没有写自动扣费或按量计费。稳妥起见，开通后在面板里确认一遍计费和限速规则。
